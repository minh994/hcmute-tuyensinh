# Tóm tắt Dự án

## Tên dự án
HCMUTE Tuyển Sinh

## Mô tả
Website tuyển sinh cho trường Đại học Sư phạm Kỹ thuật TP.HCM (HCMUTE)

## Mục tiêu
- Cung cấp thông tin tuyển sinh chính xác và cập nhật
- Tạo trải nghiệm người dùng tốt cho thí sinh và phụ huynh
- Hỗ trợ quá trình đăng ký và xét tuyển trực tuyến

## Phạm vi dự án
- Xây dựng giao diện người dùng thân thiện
- Tích hợp hệ thống quản lý thông tin tuyển sinh
- Hỗ trợ đa nền tảng (web, mobile)
- Bảo mật thông tin người dùng

## Công nghệ sử dụng
- Next.js
- TypeScript
- Tailwind CSS
- Shadcn UI
