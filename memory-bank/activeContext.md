# Ngữ cảnh Hoạt động

## Trạng thái hiện tại
- Dự án đang trong giai đoạn khởi tạo
- Đã thiết lập cấu trúc cơ bản với Next.js, TypeScript, Tailwind CSS
- Đang trong quá trình thiết kế UI/UX

## Công việc gần đây
- Thiết lập dự án Next.js
- Cấu hình TypeScript
- Tích hợp Tailwind CSS
- Thiết lập Shadcn UI
- Tạo cấu trúc thư mục cơ bản

## Công việc tiếp theo
- Thiết kế giao diện người dùng
- Phát triển các components cơ bản
- Thiết lập routing
- Tích hợp API (nếu có)
- Tối ưu hóa performance

## Quyết định và cân nhắc
- Sử dụng Next.js App Router thay vì Pages Router
- Chọn Tailwind CSS cho styling
- Sử dụng Shadcn UI cho components
- TypeScript cho type safety
- Mobile-first approach

## Học hỏi và insights
- Cần tập trung vào UX/UI cho mobile
- Cần chú ý đến performance từ đầu
- Cần thiết kế hệ thống components có thể tái sử dụng
- Cần lập kế hoạch cho SEO
